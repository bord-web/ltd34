# ltd34

Сайт-візитка майстерні підвісок мотоциклів **LTD34** (Łomianki) для домену [ltd34.pl](https://ltd34.pl).

Статичний сайт польською мовою: чистий HTML/CSS/JS, без збірки й залежностей.

## Сторінки

| Файл | Зміст |
|------|-------|
| `index.html` | Головна: послуги, чому LTD34, останні роботи, марки, контакти |
| `oferta.html` | Послуги детально, етапи роботи, для кого |
| `portfolio.html` | Портфоліо з фільтрами та галереєю (лише власні публікації профілю LTD34 на Facebook) |
| `o-nas.html` | Про майстерню |
| `kontakt.html` | Адреса, телефон, e-mail, години роботи, карта |
| `404.html` | Сторінка помилки |

Ресурси лежать у `assets/` (`css/style.css`, `js/main.js`, `img/`).

## Розміщення на ltd34.pl

Завантажити вміст репозиторію (усе, крім `.git`, `README.md`, `.gitignore`) у корінь хостингу домену (`public_html` або аналог).
Для Apache сторінку 404 можна підключити рядком `ErrorDocument 404 /404.html` у `.htaccess`.

## Додавання роботи в портфоліо

1. Покласти фото в `assets/img/portfolio/`: `назва-1.jpg` (до 1600 px) і мініатюру `назва-1-sm.jpg` (до 720 px).
2. Скопіювати будь-який блок `<article class="pf-card">` у `portfolio.html` і змінити `id`, `data-cat` (`tor`, `drogowe`, `supermoto`, `klasyki`), `data-images`, дату, заголовок, опис і посилання (`data-fb` для поста або `data-video` для відео).
